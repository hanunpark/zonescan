출고 관리 북마크 — 새 탭으로 열기

2026-11-27 · 비밀번호·키는 들어 있지 않습니다.

일반 주소 북마크로 관리 페이지를 열면 지금 보고 있는 탭(예: 루티)이 관리 페이지로 바뀝니다. 이 북마크는 어느 탭에서 눌러도 지금 탭은 그대로 두고 관리 페이지를 별도 탭으로 엽니다. 이미 열어 둔 관리 페이지 탭이 있으면 그 탭을 새로 고칩니다.

방법 A — 끌어다 놓기

  1. 북마크바가 안 보이면 Ctrl+Shift+B (맥은 ⌘+Shift+B).
  2. 아래 초록 버튼을 북마크바로 끌어다 놓습니다.
  3. 예전 관리 페이지 북마크는 우클릭 → 삭제.

출고 관리

방법 B — 붙여넣기 (끌어다 놓기가 안 될 때)

  1. [복사]를 누릅니다.
  2. 북마크바 우클릭 → 페이지 추가 → 이름 "출고 관리", URL 칸에 붙여넣고 저장.
