# zonescan

창고 존별 운송장 스캔 수집 페이지 (v2.4, 2026-11-17).

- 페이지: https://hanunpark.github.io/zonescan/
- 존 코드를 스캔한 뒤 그 존의 운송장을 스캔해 "존코드 + 운송장번호" 목록을 모읍니다.
- 스캔 기록은 폰에 저장되며, 페이지 아래 "시트 저장 주소"에 Apps Script 웹 앱 주소를 넣으면 구글 시트에도 쌓입니다.

- `pick.html` — 피킹지시서 폰 보기 (PC 피킹지시서 [전달하기] 링크로 열림)
- `driver/` — 타이어케어 아이폰 기사앱 화면 (v2, 2026-11-19). 배정확인·사전약속·출고스캔(실시간 카메라)·완료사진. 데이터는 구글시트 '기사앱_아이폰'의 Apps Script로 저장되며, 기사는 개인링크(`driver/?t=…`)로 접속합니다.
- `truck.html` — 용차출고 창고 체크 (PC 용차출고 관리의 [창고 전달 링크]로 열림)
