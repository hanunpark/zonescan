피킹 지시서 — 지시자 북마크 등록

2026-11-28 · v61 · 지시 등록(기사 배정 정식 · 미배정 임시) · 지시서 목록 · 출고 관리 · 입고예정 · 공지이 모두 들어 있는 북마크입니다.

1. PC 키 확인

관리자에게 받은 PC 키를 넣고 [확인]을 누르세요. 공유 저장소에서 지시자 키인지 확인합니다.

2. 북마크 등록 — 끌어다 놓기

  1. 북마크바가 안 보이면 Ctrl+Shift+B (맥은 ⌘+Shift+B).
  2. 아래 버튼을 북마크바로 끌어다 놓습니다. (누르지 말고 끌기)
  3. 예전 피킹지시서 북마크가 있으면 우클릭 → 삭제.

피킹지시서

끌어다 놓기가 안 될 때 — 붙여넣기

  1. [복사]를 누릅니다.
  2. 북마크바 우클릭 → 페이지 추가(또는 북마크 추가) → 이름 "피킹지시서", URL 칸에 붙여넣고 저장.

사용법

  1. 크롬에서 루티 관리자 화면(admin.flowfix.co.kr)에 로그인한 탭에서 피킹지시서 북마크를 누릅니다.
  2. 루티 창마다 피킹지시서 탭이 따로 열립니다. 같은 루티 창에서 다시 누르면 새로 그려집니다.
  3. 루티가 아닌 탭에서 누르면 루티 주문 화면을 새 탭으로 열어 줍니다 — 그 탭에서 한 번 더 누르세요.
  4. 처음 열 때 팝업이 막히면 주소창 오른쪽의 팝업 차단 아이콘에서 허용합니다.

이 북마크에는 PC 키가 들어갑니다. 북마크를 가진 사람은 지시서를 만들고 취소할 수 있으니, 지시자 PC에만 설치하세요.
